WarStalkeR — Today at 6:01 AM
In case of Harmony you need to suffer work with Prefix, Postfix, __instance and other weirdness that doesn't look like original code. In case of using BepInEx + MonoMod you just need:
namespace TargetNamespace {
  public class patch_TargetClass : TargetClass {
    [MonoModIgnore] private int variableYouWantToAccess;
    public static extern void orig_TargetFunction();
    //public static extern void orig_AnotherFunction(); //Not needed, since we're replacing it.
    public static void TargetFunction() {
      // Your code here before it.
      orig_TargetFunction();
      variableYouWantToAccess *= 2;
      // Your code here after it.
    }
    public static void AnotherFunction() {
      // Only your code here.
    }
  }
}
You can use [MonoModIgnore] to reference any internal/private function/class, as if it is part of your code. [MonoModReplace] if you decided to nuke replace entire class, nested class, function & etc. And since ILSpy provides beautiful C# code, you can easily use it as is to overwrite/replace something.
